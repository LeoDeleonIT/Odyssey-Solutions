Deleted a Work File in OneDrive or SharePoint? Start Here

Find the right Microsoft 365 recycle bin, understand recovery limits and collect the details IT needs after a work file disappears from OneDrive or SharePoint.

Published October 12, 20264-minute readPublished by Odyssey Solutions

If a work document disappears, start by identifying where it was stored and who owns it. Microsoft 365 has several recovery routes, and looking in the wrong recycle bin can make a recoverable file seem permanently lost.

Avoid emptying recycle bins, running cleanup tools or restoring an entire shared library while you investigate. Write down the file name, its original folder or link, when it was last available and the work it is blocking. Those details help your IT contact choose a focused next step.

This guide covers individual work files in OneDrive and SharePoint in Microsoft 365. Local-only files, network-server folders and other cloud services need their own recovery process.

Check whether the file was deleted or moved

Open Microsoft 365 through your usual trusted sign-in route and confirm that you are in the correct work account. Look in the original location and search for the file name. Ask a colleague who normally uses it whether it was renamed or moved.

If a link returns an access error, contact the owner before assuming deletion. Recreating the document immediately can introduce competing copies while someone else still has the original. Note what you see, including the exact error, without posting confidential documents or screenshots in a public support forum.

When the file is shared with you, identify the owner or site administrator. You may not have the permissions needed to recover it yourself. Give that person the original link rather than asking them to search every folder by description.

Use the OneDrive web recycle bin for your own files

For a file that belonged to your work OneDrive, open OneDrive on the web and select Recycle bin. Check the item carefully, select the intended file or folder and choose Restore if your organization's policy permits it. Verify the returned file in its original working location.

Microsoft says work or school OneDrive items can ordinarily be restored within 93 days of deletion unless an administrator changed the retention setting. The personal-account window is different. Neither figure is a promise that a specific item still exists or can be recovered after permanent removal. Files deleted from the cloud, including online-only files, may not appear in the computer's local Recycle Bin. See Microsoft's OneDrive recovery guidance.

Check the intended document before resuming work. Confirm the contents and date with the colleague who needs it, especially if similarly named drafts appear in the results.

Check the SharePoint site behind a team document

A document used by a team may belong to a SharePoint library rather than your personal work OneDrive. For a Teams channel file, Microsoft's instructions provide an Open in SharePoint route from the channel's files area. Use the associated site's Recycle bin and restore the specific item you need, subject to your permissions. Read Microsoft's SharePoint and Teams recovery steps.

If you cannot see the right site or recycle bin, ask its owner for help. Do not request broad administrator access just to retrieve one document. A person with the appropriate existing permissions may be able to complete the recovery and confirm the result with you.

For example, a missing proposal in a team's project library should be investigated in that library's site. Searching only the employee's laptop would leave the shared storage location unchecked.

Escalate promptly when the first recycle bin is empty

SharePoint has a second-stage, site-collection recycle bin that may require an administrator or owner. In SharePoint in Microsoft 365, the standard 93-day period runs from the original deletion across both stages. Moving an item into the second stage does not restart that clock, and earlier permanent deletion or quota-related purging can affect availability. Review Microsoft's site-collection recycle-bin guidance.

Send IT the original location and likely deletion time promptly. Ask what recovery options remain for that particular item and what evidence is needed. If the normal recycle-bin routes fail, the administrator can check the organization's retention and backup arrangements. Avoid assuming that every business bought the same protection or that every backup covers the folder involved.

A useful support request includes the filename, original link, owner or team, last-known-good time, approximate deletion time and deadline. Keep the document's sensitive contents out of the initial request unless they are necessary and the channel is approved.

Use version history when the file exists but its contents changed

A document with missing paragraphs or unwanted edits may need an earlier version rather than a recycle-bin restore. Microsoft's version-history guidance describes reviewing and restoring a previous version of a OneDrive or SharePoint file. Available history depends on the system's settings and retained versions. See the version-history instructions.

Coordinate with current editors before replacing the working version. Compare the relevant versions and preserve any legitimate newer work through an approved method. A whole-library or whole-OneDrive rollback has a wider impact and should be planned with IT, rather than used as the first response to one missing file.

If many files suddenly disappear, become unreadable or change unexpectedly, contact IT immediately and follow the incident-response process. Recovery and security investigation may need to happen together.
