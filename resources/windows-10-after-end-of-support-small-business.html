Still Running Windows 10 at the Office? What a Small Business Should Do Now

Windows 10 support ended October 14, 2025. How small businesses should inventory remaining PCs, weigh paid Extended Security Updates and plan replacements.

Published November 18, 20263-minute readPublished by Odyssey Solutions

Microsoft ended support for Windows 10 on October 14, 2025. The computers still turn on and the software still opens, which is exactly why some office PCs are still running it a year later.

What changed is that those PCs no longer receive security fixes unless the business pays for Extended Security Updates. This guide helps an office find the remaining machines and choose the right path for each one.

Know what end of support means

Since October 14, 2025, Microsoft no longer provides technical support, feature updates or quality updates, including security fixes, for Windows 10 versions that reached end of support on that date. Microsoft states that Windows 10 PCs continue to work, but recommends moving eligible PCs to Windows 11 or replacing them. Microsoft: Extended Security Updates for Windows 10

For a business, the practical risk is that newly discovered Windows vulnerabilities stay open on those machines. A PC that handles email, banking, payroll or patient records is exactly where that matters most.

Inventory every Windows 10 PC

List each computer still on Windows 10 with its user, location, purpose and age. Include the machines people forget: the front-desk check-in PC, the computer attached to a lab instrument or imaging device, the spare laptop in a drawer and the PC that only runs one old program.

For each one, note whether it can run Windows 11 and whether any software on it depends on Windows 10. Equipment-connected computers sometimes need the device vendor’s confirmation before an operating system upgrade, so ask the vendor rather than assuming.

Decide: upgrade, replace or pay for time

Eligible PCs can usually be upgraded to Windows 11 in place after a backup. Older PCs that do not meet Windows 11 requirements are usually better replaced than repaired, especially when they are several years old and already slow.

Extended Security Updates are a paid bridge, not a destination. Microsoft lists the organization price at $61 per device for year one, doubling each consecutive year, for a maximum of three years. Coverage is bought by the year and is cumulative, so an office enrolling now also pays for the first year. ESU requires Windows 10 version 22H2 and includes security updates only, with no new features or general technical support. Microsoft: Extended Security Updates for Windows 10

Handle the exceptions on purpose

If a computer truly has to stay on Windows 10, for example because it runs equipment that has not been certified for Windows 11, write that down as a documented exception. Limit what that PC does: no general web browsing or email on it, restricted network access where possible and a target date for its replacement.

Healthcare and dental practices should record unsupported systems in their security risk analysis and track the plan to address them. Our guide to HIPAA risk analysis for dental practices explains where that fits.

Retire old PCs safely

A replaced computer still holds business data. Before it leaves the office, confirm files are moved, accounts are removed and the drive is wiped or destroyed in a way you can document. Our guide to retiring business computers covers the steps.
